# Quaternius Modular Train Pack

Source: https://poly.pizza/bundle/Modular-Train-Pack-jYEybkFVr1

Creator: Quaternius

License: CC0 1.0 / Public Domain. The source page permits personal and commercial use and provides GLB downloads without an account.

Files used:

- `quaternius-electric.glb` — “High Speed Front” (`mJZDSqyzlk`), selected because it has no steam-era silhouette.
- `quaternius-passenger.glb` — “Locomotive Passenger Carriage” (`woQPFlzPHM`).

The application recolours these generic low-poly vehicles to the licensed Shosholoza Meyl photograph in `public/assets/photos/hero-train.webp`. The models do not claim to reproduce a specific South African locomotive class.

Frame 04 · Train stopped

A delay becomes useful time without inventing certainty

The interface responds to a stopped-train state, recommends content that fits the available time, and keeps the passenger safely onboard.

Simulated scenario

The operator feed is not connected in this prototype, so the delay is explicitly labelled as simulated rather than presented as live truth.

  • TriggerTrain stopped · 40-minute example.
  • ResponseCached content ranked by available time.
  • SafetyNo instruction to leave the train.
Design distinctionThe duration bracket is a system state. It must not be mistaken for a precise geographic point or confirmed operator information.
